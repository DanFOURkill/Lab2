# Романтичный сайт-приглашение на свидание

Готовый адаптивный одностраничный сайт-приглашение, который полностью работает локально: достаточно открыть `index.html` в браузере.

## Возможности

- четыре плавных экрана: приглашение, дата, еда и итог;
- убегающая кнопка «Нет» с безопасным позиционированием внутри карточки;
- растущая кнопка «Да», конфетти и взлетающие сердечки;
- выбор будущей даты и времени с быстрыми вариантами;
- выбор еды или собственный вариант;
- итоговая карточка, копирование приглашения, скачивание текста и скачивание ответов в JSON;
- сохранение подтверждённого свидания в LocalStorage конкретного браузера;
- полностью адаптивный glassmorphism-дизайн без фреймворков.

## Настройка

В начале `script.js` измените объект `CONFIG`:

```javascript
const CONFIG = {
  girlName: "Имя девушки",
  authorName: "Твоё имя",
  mainQuestion: "Пойдёшь со мной на свидание?",
  introductoryText: "Я подготовил для тебя кое-что особенное ❤️",
  finalMessage: "Буду очень ждать нашей встречи ❤️",
  locale: "ru-RU",
};
```

## Где сохраняется выбор

После нажатия кнопки «❤️ Подтвердить свидание» выбранные дата, время и еда сохраняются в `LocalStorage` браузера девушки под ключом `romantic-date-invitation`.

Важно: `LocalStorage` — это локальное хранилище конкретного браузера и профиля. Вы не увидите её выбор автоматически на своём устройстве и не получите его на сервер, потому что проект полностью локальный и серверной части нет.

Чтобы передать результат, на итоговом экране есть три локальных способа:

1. «📋 Скопировать приглашение» — скопировать красивый текст в буфер обмена.
2. «📄 Скачать приглашение» — скачать текстовый файл `date-invitation.txt`.
3. «📦 Скачать ответы JSON» — скачать технический файл `date-invitation-answers.json` с датой, временем, едой и временем сохранения.

## Русский язык в браузере

В проекте уже указаны `lang="ru"` в `index.html` и `locale: "ru-RU"` в `script.js`, поэтому тексты интерфейса и формат даты выводятся по-русски.

Нативные поля `<input type="date">` и `<input type="time">` отображаются средствами браузера/операционной системы. Их язык обычно зависит от языка браузера или системы. Если календарь браузера показывается не на русском, включите русский язык в настройках браузера:

- Chrome/Edge: Settings → Languages → Add languages → Russian → Move to top / Display browser in this language.
- Firefox: Settings → General → Language → Choose → Russian.
- Safari: язык берётся из macOS/iOS: System Settings → General → Language & Region.

## Запуск

Откройте файл `index.html` двойным кликом или перетащите его в окно браузера.
