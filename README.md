# Lab2 — интерактивное романтическое приглашение

Проект — адаптивный веб-сайт на Next.js App Router для создания персонального приглашения на свидание, прохождения интерактивного сценария получателем и просмотра статуса автором.

## Требования

- Node.js 20 или новее.
- npm 10 или новее.
- Доступ к npm registry для установки зависимостей.

## Быстрый запуск

```bash
npm install
npm run dev
```

После запуска откройте в браузере:

- главная страница: <http://localhost:3000>
- конструктор приглашения: <http://localhost:3000/create>
- демо-приглашение: <http://localhost:3000/invite/demo>
- dashboard демо-приглашения: <http://localhost:3000/dashboard/demo>

Команда `npm run dev` сначала выполняет `prisma db push`, чтобы подготовить локальную SQLite-базу, а затем запускает `next dev`.

## Переменные окружения

Для локальной разработки используется SQLite. Значение уже добавлено в `.env`:

```env
DATABASE_URL="file:./dev.db"
```

Файл базы будет создан Prisma внутри директории `prisma/` при первом запуске `npm run dev`.

## Основные команды

```bash
npm run dev
```

Запускает локальный сервер разработки на <http://localhost:3000> и синхронизирует SQLite-схему.

```bash
npm run build
```

Генерирует Prisma Client и собирает production-версию Next.js приложения.

```bash
npm run typecheck
```

Проверяет TypeScript без генерации файлов.

```bash
npm run lint
```

Запускает ESLint-проверку проекта.

```bash
npm run test
```

Запускает Vitest + React Testing Library тесты основного пользовательского сценария.

## Как пользоваться приложением

1. Перейдите на `/create`.
2. Заполните имя получателя, имя отправителя, тексты приглашения, варианты дат, форматы свидания, контакт отправителя и визуальную тему.
3. Нажмите «Создать приглашение».
4. Скопируйте ссылку `/invite/[slug]`, откройте её или отправьте через кнопку «Поделиться».
5. Получатель проходит интерактивную историю, выбирает дату и формат встречи, затем подтверждает ответ.
6. Автор открывает `/dashboard/[slug]`, чтобы увидеть статус приглашения, выбранную дату, формат, комментарий и время последнего действия.

## Где менять настройки и контент

- Демо-тексты, даты и форматы свидания: `lib/defaults.ts`.
- Типы шагов, приглашения и ответа: `lib/types.ts`.
- Zod-валидация конструктора и ответа: `lib/validation.ts`.
- Основной сценарий приглашения и reducer: `components/invitation/InvitationShell.tsx`.
- Экраны приглашения: `components/invitation/`.
- Форма конструктора: `components/creator/InvitationForm.tsx`.
- Редактор дат: `components/creator/DateOptionsEditor.tsx`.
- Редактор форматов свидания: `components/creator/ActivityOptionsEditor.tsx`.
- CSS-переменные тем и базовая визуальная система: `app/globals.css`.
- Prisma-модели: `prisma/schema.prisma`.

## Локальная база данных

При первом запуске `npm run dev` Prisma создаст SQLite-базу и применит схему через `prisma db push`.

Если нужно сбросить локальную базу:

```bash
rm -f prisma/dev.db
npm run dev
```

После повторного запуска демо-приглашение `/invite/demo` будет создано автоматически при первом обращении к данным.

## Проверка перед отправкой изменений

Рекомендуемый набор команд:

```bash
npm install
npm run typecheck
npm run lint
npm run test
npm run build
```

Если `npm install` падает с ошибкой `403 Forbidden`, проверьте доступ к npm registry, настройки proxy и корпоративные политики доступа к пакетам.
